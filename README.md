#  Análise Exploratória: Dataset de Filmes

> **Projeto desenvolvido para o Bacharelado em Ciência de Dados - UNIVESP**  
> **Objetivo:** Portfólio para processo seletivo de Estágio Curricular

## 👤 Sobre o Projeto
Este projeto foi desenvolvido como parte da minha formação em Ciência de Dados na UNIVESP e tem como objetivo demonstrar habilidades práticas em:
- Coleta e carregamento de dados de fontes externas
- Limpeza e exploração de dados (EDA - Exploratory Data Analysis)
- Visualização de dados com Matplotlib e Seaborn
- Análise estatística descritiva
- Documentação e comunicação de insights

## 🎯 Objetivos da Análise
- Explorar um dataset público de filmes (7.668 registros)
- Identificar padrões de avaliação (scores) e tendências temporais
- Analisar gêneros mais frequentes no mercado cinematográfico
- Praticar o uso de Python, Pandas e bibliotecas de visualização

## ️ Ferramentas e Tecnologias
- **Python 3.12.8**
- **Pandas** - manipulação e análise de dados
- **Matplotlib** e **Seaborn** - visualização de dados
- **Jupyter Notebook** (VS Code) - ambiente de desenvolvimento

## 📊 Principais Insights

### 1. Tendência Temporal
- A produção de filmes está concentrada nos anos mais recentes (2018-2020)
- Total de 1.825 filmes nos últimos 10 anos analisados

### 2. Qualidade das Avaliações
- **Nota média (score): 6.39**
- Mediana: 6.5
- A maioria dos filmes concentra-se entre 6.0 e 7.0
- Distribuição relativamente simétrica

### 3. Gêneros Predominantes
1. **Comedy**: 2.245 filmes
2. **Action**: 1.705 filmes
3. **Drama**: 1.518 filmes
4. **Crime**: 551 filmes
5. **Biography**: 443 filmes

## 🔧 Desafio Superado
**Problema identificado:** A coluna 'rating' continha classificação indicativa (PG, R, G) em vez de notas numéricas.  
**Solução:** Identifiquei e utilizei a coluna 'score' para as análises estatísticas, demonstrando atenção aos detalhes e validação de dados.
